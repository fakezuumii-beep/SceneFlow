# SceneFlow Skill

## When to use SceneFlow

Use SceneFlow when the user wants to turn a script or an existing audio file into a complete single-host podcast or talking-head video.

SceneFlow can handle:

- script-to-video
- audio-to-video
- TTS
- speech transcription
- semantic storyboarding
- automatic video editing
- A-roll / B-roll planning
- stock B-roll retrieval
- MuseTalk lip-sync
- subtitles
- MP4 export

## Typical user requests

Examples:

- Turn this script into a podcast video.
- Turn this audio into a complete video.
- Create a talking-head video with automatic B-roll.
- Use MuseTalk to generate presenter A-roll.
- Automatically storyboard my narration.
- 把这段文案生成一个完整的播客视频。
- 把这段音频自动配上画面、人物口型和字幕。
- 我不会剪辑，帮我自动生成一个口播视频。

## Intended audience

SceneFlow is designed for users who want a simple workflow and do not want to manually build a complex AI video pipeline.
