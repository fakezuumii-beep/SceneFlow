# 单人 InfiniteTalk A-roll

在「连接与设置 → A-roll 人物口型」选择「单人影片 · InfiniteTalk Q8」。先启动已有 ComfyUI，再点「测试状态 / 连接」。工作台会检查节点和模型选项；无需在工作台里重复安装模型。

人物输入使用所选人物图片；选择循环视频时，使用其封面图片驱动新视频。原音频按连续 A-roll 区间切片，相邻 A-roll 共用一次生成和一个视频文件，各镜头保留自己的入点。生成后自动取回 MP4，检查解码、25fps 和帧数，接入预览及导出。生成不足时会报错，不循环或冻结画面补齐。

生成帧数按音频长度计算，多请求 1 帧并加入 0.12 秒静音尾部供安全裁切；若 InfiniteTalk 的窗口拼接仍丢失尾帧，只对这个失败区间增加尾部余量并重试。音频驱动和输出都使用 25fps。单个连续区间最多 10000 帧。16:9 时沿用工作流原尺寸；本期画幅选 1:1 时，会把人物输入后的可调缩放节点改为正方形；选择 9:16 时使用 480×832 原生竖向推理，再规范裁切为标准竖屏成片。模型、采样步数和动作提示词不变。1080p 导出不会增加底层工作流的原生细节。

已成功生成的片段会复用。人物、音频、时间边界或工作流变化会使对应缓存失效；手动重生成会保留旧视频历史。停止工作台任务只撤回它自己的排队任务，已经在 ComfyUI 中运行的推理继续完成，下次可取回。网络中断时保留任务编号；提交结果不明确时禁止自动重复提交。

首次从已有单人画布接入，可运行：

```powershell
.venv\Scripts\python.exe tools\connect_infinitetalk.py "你的单人工作流.json" --url http://127.0.0.1:8188
```

该工具把画布转换为 API 格式副本，存到 `data/private/workflows`，备份原连接设置后选择 InfiniteTalk。原画布和 ComfyUI 模型不变。它适用于 LoadImage → 单音轨 MultiTalkWav2VecEmbeds → VHS_VideoCombine 的工作流，不是任意画布转换器。
